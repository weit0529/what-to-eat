# 菜单填写说明

网站上能抽到的菜，全部来自 `data/menu.xlsx` 这个 Excel 表格。改菜单只需要改这个表格，不用碰代码。

---

## 一、最快上手

1. 用 Excel（或 WPS）打开 `data/menu.xlsx`
2. 在“菜单”这一页里增加、修改或删除行，每行一道菜
3. 保存，**关掉 Excel**
4. 检查有没有填错（见第五节）
5. 发布到网上（见第七节）

> 表格的第一行是列名，**不要改列名**。鼠标停在列名上，会显示这一列怎么填。

---

## 二、每一列怎么填

| 列名 | 必填 | 怎么填 | 例子 |
|---|---|---|---|
| **品类** | ✅ | 吃的是什么 | 麻辣烫 |
| **店铺** | | 具体哪家店。不填就是泛指这个品类 | 公司楼下 |
| **分类** | ✅ | 大类，**只填一个**。用来“今天不想吃这一类”时整类勾掉 | 火锅串串 |
| **适合餐次** | ✅ | 早餐、午餐、晚餐，以及“餐次”页里加的餐次（如下午茶、夜宵）中的一个或几个；或者填“全天” | 午餐、晚餐、夜宵 |
| **标签** | | 自由填，几个标签用顿号隔开。分析推荐时会用到，建议用第六节的写法 | 辣、热乎、适合下雨 |
| **人均价格** | | **只填数字**，单位是元 | 25 |
| **描述** | | 一句话介绍，会显示在结果卡片上 | 汤底浓，可以自己挑菜 |
| **图片** | | 图片的文件名，图片放在 `public/images/` 文件夹里（见第四节） | malatang.jpg |
| **启用** | | 填“否”就暂时不出现在网站上，不用删行；不填等于“是” | 否 |

### 填写规则

- **一道菜靠“品类 + 店铺”来认**，所以同一个品类可以有多家店，但“品类 + 店铺”完全一样的不能出现两次。改了品类或店铺的名字，就会被当成一道新菜。
- **用什么隔开**：标签和餐次可以用顿号 `、`、逗号 `，` `,`、分号 `；` `;` 隔开，也可以换行。
- **适合餐次认得的词**：早餐、早饭、早；午餐、午饭、午；晚餐、晚饭、晚；全天；再加上“餐次”页里加的餐次名字（见下面第三节）。**“全天”只代表早、午、晚**，不包括下午茶、夜宵这些，想要的话另外写上。没加过的词（比如“宵夜”）会报错。
- **启用认得的词**：是 / 否；也认 yes、no、1、0，以及 Excel 里的 TRUE、FALSE。
- **人均价格**：`25`、`12.5` 都可以；`25元`、`约25`、负数会报错。
- **分类的小图标**：网站会按分类名自动配一个 emoji，比如带“面”字的配 🍜、带“火锅”的配 🍲，认不出的用 🍽️。
- **空行**会被跳过，可以拿来分隔。
- **多出来的列**会被忽略，可以加一列“备注”写给自己看。
- **emoji**：菜名、描述、标签里可以写 emoji，但请用 Excel 或 WPS 直接填。用程序脚本改过的表格，emoji 可能被读成别的字。
- **工作表**：网站读第一个工作表（“菜单”）和名叫“餐次”的工作表。“填写说明”那一页不会被读取。不要把别的工作表拖到“菜单”前面。

## 三、加餐次（下午茶、夜宵……）

早、午、晚三个是固定的。想加别的餐次，在“**餐次**”这一页加一行：

| 列名 | 必填 | 怎么填 | 例子 |
|---|---|---|---|
| **餐次** | ✅ | 餐次的名字 | 夜宵 |
| **图标** | | 一个 emoji，显示在按钮上；不填会自动配一个 | 🌃 |

- 加了以后，“菜单”页的“适合餐次”就能填这个名字；网页上会在早、午、晚按钮下面多出一个按钮
- 最多加 6 个；名字不能重复，不能和早餐、午餐、晚餐、全天这些固定的词重名，名字里不能有顿号、逗号、分号、空格
- 不想要了，把那一行删掉，再把“菜单”页里用到这个名字的地方去掉（不然检查会报“不认识”）
- 图标如果显示成别的字或者被提醒“不是 emoji”，是保存表格的工具把 emoji 存坏了；用 Excel 或 WPS 重新填一下即可，不填也没关系

---

## 四、加图片

1. 把图片放进项目的 `public/images/` 文件夹
2. 在“菜单”页的“图片”列里填**文件名**，比如 `malatang.jpg`，不要带文件夹

建议：

- **格式**：jpg、jpeg、png、webp、gif 都可以，推荐 jpg 或 webp
- **大小**：宽 800 像素左右、每张 300 KB 以内，手机打开快
- **形状**：横图（宽 : 高大约 16 : 10）。卡片会按这个比例裁剪，太竖的图会被裁掉上下
- **文件名**：用英文小写或拼音，例如 `niu-rou-mian.jpg`。**大小写要和表格里完全一样**：在自己电脑上 `A.jpg` 和 `a.jpg` 可能都能打开，发布到网上就只认完全一样的
- 没有图片也完全没关系，卡片会显示一个大大的分类 emoji

图片找不到、文件名不对时，**不会挡住发布**，只会提醒你，这道菜先不显示图片。

## 五、检查有没有填错

在项目文件夹里打开命令行，运行：

```
npm run menu
```

- 全部正确时会显示：`菜单检查通过：共 34 道菜可用，另有 1 道暂停。`
- 有错误时会列出每一处，写明**第几行、哪一列、哪里不对**。按提示改好再运行一次即可。

常见的错误和改法：

| 看到的提示 | 原因 | 怎么改 |
|---|---|---|
| 第 3 行「分类」：不能为空 | 必填项没填 | 补上 |
| 第 3 行「分类」：只能填一个分类 | 分类里写了“火锅、川菜”这样的多个 | 只留一个 |
| 第 3 行「适合餐次」：不认识“宵夜” | 写了不认得的餐次 | 改成早餐、午餐、晚餐或全天 |
| 第 3 行「人均价格」：“25元”不是数字 | 价格里有文字 | 只留数字 `25` |
| 第 5 行「品类」：和第 2 行重复 | “品类 + 店铺”和别的行一样 | 改个店铺名，或者删掉一行 |
| 第 1 行「适合餐次」：缺少这一列 | 列名被改了或删了 | 把列名改回原样 |
| 「餐次」页第 3 行「餐次」：…… | “餐次”页填得不对 | 按提示改“餐次”页 |
| 第一页应该是菜单 | “餐次”页被拖到了最前面 | 把“菜单”页拖回最前面 |
| 所有菜都填了“启用：否” | 网站上没菜可选了 | 至少启用一道 |
| 读不了菜单表格 | 文件不是 .xlsx，或者还开着没保存好 | 用 Excel“另存为”→“Excel 工作簿 (.xlsx)”，关掉再试 |

**表格有错误时，网站不会发布成错的菜单**：构建会停下来，网上的版本保持原样。

想在电脑上先看看效果，运行 `npm run dev`，然后用浏览器打开 http://localhost:5173 。

## 六、建议标签

标签可以随便写，不强制用下面这些。但**同一个意思最好用同一种写法**（比如统一写“辣”，不要一会儿写“辣”一会儿写“麻辣口”），以后“分析需求”模式按标签推荐时会更准。

| 方面 | 建议写法 |
|---|---|
| 口味 | 辣、微辣、麻、酸辣、酸甜、甜、咸香、清淡、重口 |
| 吃起来 | 热乎、冷食、汤、下饭、管饱、油炸 |
| 健康 | 低卡、健康、养胃、素、肉 |
| 价格和速度 | 实惠、快、想吃好点 |
| 天气 | 适合下雨、适合天冷、适合天热 |
| 心情 | 犒劳自己、治愈、提神 |
| 几个人 | 适合一个人、适合两个人、适合多人 |
| 时间 | 夜宵 |

预算不用写成标签，填在“人均价格”一列就行。

## 七、发布到网上

网址：**https://weit0529.github.io/what-to-eat/**

改好表格、检查通过后，把改动提交并推送到 GitHub，网站会在几分钟内自动更新。

### 方法一：让 Claude 帮你

告诉 Claude“菜单改好了，帮我发布”，它会检查、提交，问过你之后再推送。

### 方法二：自己用命令行

在项目文件夹里依次运行：

```
npm run menu
git add data/menu.xlsx public/images
git commit -m "更新菜单"
git push
```

- 第一行先检查表格，**有错误就先改好，不要往下做**
- 只加了菜、没加图片时，第二行照写也没关系
- 第一次推送可能会弹出 GitHub 登录窗口，登录即可

### 推送之后

1. 打开 https://github.com/weit0529/what-to-eat/actions ，最上面一条就是这次的发布
2. 等 1～3 分钟：绿色 ✓ 表示发布成功；红色 ✗ 表示失败，点进去看是哪一步。最常见的原因是表格有错误，这时网上还是原来的菜单，改好表格再推送一次即可
3. 打开网址刷新一下就能看到新菜单。手机上如果还是旧的，多刷新一次或者稍等一会儿

> 网站代码和菜单表格都是公开的，任何人都能看到表格里写的内容。
